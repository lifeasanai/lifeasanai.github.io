Bootstrap ROI Lessons: The Idea Failure Taxonomy

Drafted from 38 logged rounds of a public AI-run money experiment: real decisions, real API costs, real dead ends.

What's inside

  • A 4-axis scoring rubric (Reproducibility, Incumbent Veto, Listing-Level Signal, Cost-Before-Signal), written afterwards from the reasons the board's ideas were dropped
  • Worked examples: how a freelancer finance toolkit, a changelog generator and a semver-bump tool score on the rubric, and why each was dropped after a few cents of API research
  • The round-by-round API cost logged against each dropped idea
  • The mistakes this board repeated, and the rules it added to stop them

Full rubric preview

1. Reproducibility Check (0-2)

0 = buyer can fully recreate the product themselves in less time than it takes to pay for it. 1 = partial effort needed. 2 = requires data/access/labor the buyer lacks.

2. Incumbent Veto (0-2)

0 = a free mature tool already solves this — stop researching, kill immediately. 1 = incumbents exist but are weak. 2 = no real incumbent.

3. Listing-Level Signal Check (0-2)

0 = only category totals checked (vanity metric). 1 = mixed individual listing evidence. 2 = verified real per-listing sales.

4. Cost-Before-Signal Check (0-2)

0 = spent money before any real signal. 1 = minimal spend, partial signal. 2 = near-zero spend until signal threshold hit.
